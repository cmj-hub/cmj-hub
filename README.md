## About

Open-source GTM skills for Claude Code. Ten MIT packs cover the jobs a founder searches for: ideal customer profile, value proposition, cold email, LinkedIn posts, pricing strategy, landing page, generative engine optimization, sales offer, sales prospecting, and email sequence.

The build guide teaches a human. The pack teaches an agent. Each scorer is Python in the repo. It does not call a paid API.

The packs install into Claude Code, Cursor, Codex, Grok, Copilot, Windsurf, Cline, and OpenCode.

---

## Quickstart

```bash
# Ideal customer profile
npx skills add cmj-hub/claude-psp --all -g --full-depth

# Value proposition
npx skills add cmj-hub/claude-evp --all -g --full-depth

# Cold email
npx skills add cmj-hub/claude-cold-email --all -g --full-depth

# LinkedIn posts
npx skills add cmj-hub/claude-founder-brand --all -g --full-depth

# Pricing strategy
npx skills add cmj-hub/claude-pricing --all -g --full-depth

# Landing page
npx skills add cmj-hub/claude-landing-page --all -g --full-depth

# Generative engine optimization
npx skills add cmj-hub/claude-geo --all -g --full-depth

# Sales offer
npx skills add cmj-hub/claude-sales-offer --all -g --full-depth

# Sales prospecting
npx skills add cmj-hub/claude-prospect-list --all -g --full-depth

# Email sequence
npx skills add cmj-hub/claude-email-sequence --all -g --full-depth
```

Everything here is MIT licensed. The same command works in Claude Code, Cursor, Codex, Grok, Copilot, Windsurf, Cline, and OpenCode.
